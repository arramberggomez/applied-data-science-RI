# US Air Quality: Multi-Station Aggregation & Pollution Forecasting

**Task:** supervised regression / spatiotemporal forecasting. We merge and clean daily air-quality measurements (NO₂, O₃, SO₂, CO) from US monitoring stations (2000–2016), engineer temporal (lags, rolling windows, seasonality) and spatial (neighbouring-station) features, and forecast next-day AQI. Advanced models are compared against naive baselines.

**Dataset:** [Kaggle – US Pollution Data](https://www.kaggle.com/datasets/sogun3/uspollution)

Download the dataset, extract `pollution_us_2000_2016.csv` from the zip and save it in `data/raw/`. The data is not committed to the repository. Alternatively, `just download` does it automatically.

## Setup

### Requirements
- [uv](https://docs.astral.sh/uv/) manages Python and the dependencies. You don't need to install Python yourself: `uv` downloads the correct version automatically.
- [just](https://just.systems/) is the command runner.

| OS | Install |
|----|---------|
| Linux (Arch) | `sudo pacman -S uv just` |
| Windows | `winget install --id astral-sh.uv -e` and `winget install --id Casey.Just -e` |
| macOS | `brew install uv just` |

Then install the project dependencies:
```sh
just setup
```

## Usage

The pipeline runs in stages. Each stage reads the previous stage's output from disk, so you can re-run any stage on its own. Output folders are created automatically.

```sh
just download                  # data/raw
just run clean                 # data/processed (add --nrows 100000 for a quick sample)
just run eda                   # report/figures
just run features              # data/processed
just run train                 # models/
just run evaluate              # report/tables (--split test only for the final evaluation)
just all                       # everything above
```

| Command | Description |
|---------|-------------|
| `just` | List all available commands |
| `just setup` | Install/update dependencies |
| `just run <step>` | Run one pipeline step |
| `just lint` / `just fmt` | Check / auto-format the code with ruff |
| `just add <library>` | Add a library to the environment |
| `just requirements` | Export `requirements.txt` from the lockfile |
| `just report` | Build `report/main.pdf` |

Without `just`, every recipe has a plain equivalent, e.g. `uv run python -m applied_data_science_ri clean`.
